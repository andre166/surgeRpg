# Inflation RPG - Enemy & Boss data (reverse-engineered)

Source: decompiled AS3 under `reverse/decomp/scripts/` (read-only). All line references are `file:line` in that tree.
Machine-readable companion: `reverse/extracted/enemies.json` (generated by the same extraction; 780 enemy entries, 64 boss entries, full `StageLvData` table, exp-table samples).

Romanized terms: *teki/ene* = enemy, *tekisei* = suitable (recommended) level, *kakuritu* = probability, *nokori* = remaining, *bounasu/bonas* = bonus, *renzoku* = combo, *crih/cri* = critical, *buki* = weapon, *bougu* = armor, *akuse* = accessory, *hakken* = discovered, *kyarakuta* = character.

## 1. Enemy loading pipeline and parameter semantics

### 1.1 Call chain

1. `StageMap.BattleStertFunc(bossId=-1)` decides bonus type and event boss, then calls `ga.battle.eneDataLoad(BounasSyu, info.MapNum, StageSLV, BossSyu)` (`StageMap.as:1879`).
2. `BattleVar.eneDataLoad(BounasSyu, map, lv, BossSyu=-1)` (`BattleVar.as:88-100`) stores bonus/map/level/boss, computes player stats (`myStatusSet`, `BattleVar.as:239-281`), asks `DataMana_WinOrLose.StartEneDataLoad(BossSyu)` whether this boss was already beaten this run (`isWinBoss`), and calls `EneData.eneload(ga, BossSyu, map, lv, isWinBoss)`.
3. `EneData.eneload` (`Include_GameData/EneData.as:27-3065`) selects a table by `map`/`lv`, rolls `eneSyu` with `kakuritu(weights)`, sets `tekiseiLvBai`, and calls its private `eneLoad(...)` (`EneData.as:22-25`), which forwards to `BattleVar.eneLoad(sprite, isWinBoss, ...)`. Bosses go through `EneData_Boss.eneload(ga, BossSyu, map, lv)` (`EneData.as:112-119`, `EneData_Boss.as:26-341`) with the same `eneLoad` shape (`EneData_Boss.as:21-24`).
4. `BattleVar.eneLoad` (`BattleVar.as:102-237`) converts the raw parameters into battle values (hard-mode multipliers, EXP formula, bonus effects, drop setup, probabilities).

Enemies have **no DEF / AGI / LUCK fields**. Their defensive strength is the derived `enePoint` (section 3.4), which is computed from HP, ATK, EXP, gold and the area level.

### 1.3 Weighted selection `kakuritu(weights)` (`EneData.as:77-104`)

```
sum = Σ w[i]
r   = int(sum * Math.random() + 0.5)      // 0..sum
pick first i with cumsum(w[0..i]) >= r
```
So `P(i) = w[i]/sum`, except the first bucket gets `+0.5/sum` and the last `-0.5/sum` (rounding bias). If `eneSyu` was already fixed (`eneSyu != -1`) the function returns it unchanged (`:80-83`). `BounasuKakurituData.kakuritu` is identical but returns the last index on fall-through (`BounasuKakurituData.as:151-178`).

### 1.4 Map / level context

- `StageSLV` (the "lv" argument, 0-based) is looked up in `StageLvMap[map-1][gy][gx]`, a grid indexed by the player's position on the map (`StageMap.as:1430-1470`, grids in `MapData.as:48-167`).
- **Area level** (shown as "適正LV" and used by the EXP formula) is `StageLvData[map-1][lv][0]` (`BattleVar.as:116`, `MapData.as:49-178`). Columns `[1]`,`[2]` are only the % position of the level label on the map (`StageMapVar.as:472-473`). Full table in section 8.
- `tekiseiLvBai` is set per `(map, lv)` block in EneData and is a **multiplier** on the one-level exp of the area level (see 3.1), not a level. `-2` = "p6 is raw EXP"; `-1` = unset.
- Maps 17-55 (the small "smyada" maps) share one table with 10 levels (`EneData.as:1963-2127`, `MapData.as:119-124`). Map 16 reuses the map-15 lv6 trio (`:1939-1962`); maps 59/60 reuse `ene15_6a-c` with different tekisei (`:2277-2316`). Map 57 has one pool for all 7 levels (`:2216-2248`). Maps 61-68 share eleven helper pools named after the area level they are for (`map47500 ... map93333`, `:2319-2558`), called with per-map weights (`:2559-2741`). Maps 69-72 and 73-77 are **formula tables** (section 3.3). Any map 1-99 with no table gets a 50x50 blank placeholder enemy (`:3051-3063`, unreachable for maps 1-77).

### 3.4 `enePoint` - the enemy's derived "defense" (`BattleVar.as:283-315`)

```
enePoint = EneHP/15 + EneATK/2 + EneExp/475000 + EneG/50     // after hard multipliers, before bonus/luck multipliers
enePoint = (enePoint*2 + areaLv*3) / 5                        // int truncation on each assignment
if areaLv >= 20000: enePoint *= 1.05
if drop1: +5   if drop2: +10   if drop3: +15     (checked after the hard-mode table swap)
if drop1: *1.05  if drop2: *1.075  if drop3: *1.1
```
Used for: player damage reduction (`Battle.as:925-944`: `d = enePoint (x1.1 hard); if d > atkDmg: d = (d*3 + atkDmg*2)/5; d *= 0.3; if d >= 0.32*atkDmg: d = (d + 0.32*atkDmg*99)/100; d += rand*enePoint*0.02 + enePoint*0.02; if d >= 0.44*atkDmg: d = (d + 0.44*atkDmg*199)/200; dmg = (atkDmg - d) * 0.88 ± 10% + rand(4)-2`) and for the probability tier below.

### 3.6 Enemy attack damage (`Battle.as:962-1003`)

```
d = (ATK*2 + (ATK - def*0.5)*12) / 14
if d < 0.5*ATK: d = (0.5*ATK + d)/2
if d < 0.3*ATK: d = (0.3*ATK*3 + d)/4
if d < 0.2*ATK: d = (0.2*ATK*5 + d)/6
if d < 0.1*ATK: d = (0.1*ATK*7 + d)/8
d = d ± 10% + rand(4) - 2 + rand*ATK*0.0225 + ATK*0.0025
if d <= 0: d = myhpm < 100 ? rand*myhpm*0.09 + 1 : rand*10 + 1
d = floor(d)
```
